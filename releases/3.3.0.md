# Ąlpha Şquad UI 3.3.0

This update makes group preparation more reliable and settings easier to use across window sizes, while tightening sharing controls and the release process.

## Interface and HUD

- Opening settings from the gameplay shortcut provides immediate mouse access and restores the previous input state on close.
- Settings reorganize their navigation and cards on narrower screens instead of uniformly shrinking the entire interface.
- Move HUD keeps a compact toolbar with one contextual instruction. Drag to move, use corners for proportional resizing and edges to reshape, then choose Done. Existing examples and Live data remain available; no extra placement modes are introduced.
- Group Ultimate rows keep their configured size when the number of matching players changes. Charge-only updates avoid unnecessary geometry work.
- Builds keeps an unchanged item, skill or Champion tooltip open during routine refreshes. Selecting another player or changed data updates its content safely.
- Effects with multiple contributors offer a compact player choice before opening a build.

## Coverage and sharing

- Same-session set reports survive Support Coverage OFF/ON, while group departure, offline state and character changes invalidate inappropriate data.
- Coverage recognition uses verified native identities and preserves the required evidence through build serialization. Supported Scribing combinations are checked against their scripts and beneficiaries; an unsupported or unreadable recipe remains unknown.
- The companion uses the same native sharing-control bridge as the full addon. Its status reflects actual sending availability, and OFF revokes queued personal data through the supported protocol boundary without clearing another addon's traffic.
- Existing sharing choices and account/character preferences remain supported. Update the companion together with the full suite when other players use it.

## Distribution and project security

- Versioned full-suite and companion archives are built once, validated after extraction and distributed with SHA256 checksums and source provenance.
- CI dependencies are pinned to reviewed commits. Automated checks cover new credential/identity exposures, metadata consistency, incoming changes, Lua 5.1/5.4 and both installable packages.
- The project now includes an MIT license, a private vulnerability-reporting policy, ownership guidance and reviewed repository-policy configuration. Configuration files do not claim that administrator-only GitHub settings have been applied.

## Compatibility and validation

No SavedVariables reset is required. Existing Ultimate display modes, themes, module states, library choices and supported layout settings remain intact.

Automated checks establish code and package consistency, not native rendering or measured game performance. The [client acceptance matrix](https://github.com/ALPHASQUADUI/Alpha-Squad-UI/blob/v3.3.0/docs/CLIENT_ACCEPTANCE.md) records the mouse/controller, screen-size, transformation, group-transition and frame-time checks still to perform in ESO.

Build transport IDs **507/510 remain provisional**; this update does not reserve them or establish public coexistence certification. A compatible consenting sender is required for remote builds. Broadcasts are visible to the group, and consistent received data is not independent proof of another player's equipment. The lightweight companion does not replace a LibGroupCombatStats sender for live Ultimate charge.
