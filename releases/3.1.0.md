# Ąlpha Şquad UI 3.1.0

## Interface and placement

- MOVE HUD keeps proportional corner scaling continuous. Edges reshape the selected panel without stretching native icons. Screen fitting no longer applies the same scale twice.
- Personal Ultimate starts smaller on new installations. Personal and Group Ultimate have explicit Horizontal and Vertical layouts; dragging across a width threshold no longer switches layouts unexpectedly.
- Preview supplies twelve fictional group members with native Ultimate icons and ready, charging, spent, unavailable and offline examples. Support previews include covered, missing, unknown, duplicate and disabled states. Preview data stays inside the editor.
- Keyboard and controller navigation reaches settings, details and editor controls. A native gamepad Settings entry and configurable Open/Move HUD bindings provide access without chat commands. Native device glyphs describe the available actions.
- Builds preserves the mannequin's native proportions, centers its body and aligns paired equipment columns. Settings, Builds and tooltips use logical dimensions consistently when UI scaling changes.
- Viewport changes end an active drag and refit the interface while preserving the requested geometry. Native confirmations and other scenes release the addon's input layer.

## Coverage and data

- Corrected source identities that could mistake Blastbones for Boneyard, Blazing Spear for Luminous Shards, or Corrosive Armor for Magma Shell, together with additional class and mastery mappings.
- Every catalog entry resolves native artwork or an identified native category symbol. No invented skill artwork or downloaded icon pack is used.
- Verified Banner Scribing recipes use native script slots and valid combinations. Unsupported combinations remain unknown. Normal and Perfected set families retain separate front/back contributions when supplied by LibSetDetection.
- Incoming builds receive stricter item-slot, script, Champion, mastery and consumable checks. Late packets cannot restart expired transfers, and repeated summaries cannot keep expired full builds alive.
- Companion scans are coalesced; consumable changes use lightweight updates. Initial capture waits until the character is active. Existing sharing OFF choices remain preserved.

## Updating

Replace the `AlphaSquadUI` folder and reload the UI. Update the optional `AlphaSquadBuildShare` companion on players who use it. No SavedVariables reset is needed. Existing sizes and sharing choices remain authoritative; use MOVE HUD's Reset for the new compact defaults.

Choose a panel, select Horizontal or Vertical where available, and use Preview before adjusting it. Corners scale the whole panel; edges adjust width or height. Controller users can cycle Move, Scale, Width, Height and Controls modes using the on-screen hints.

Automated validation covers both Lua runtimes, syntax, manifest/XML consistency and both installable packages. Native rendering, device transitions, network coexistence and frame time still need the [ESO client checks](../docs/SUPPORT_COVERAGE_TESTING.md). See the [engineering audit](../docs/AUDIT_3.1.0.md), [catalog evidence](../docs/CATALOG_EVIDENCE.md) and [data security review](../docs/SECURITY_REVIEW.md) for scope and remaining limits.
