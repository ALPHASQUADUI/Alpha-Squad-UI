# Ąlpha Şquad UI 3.0.0

## One personal Ultimate HUD

- Normal Ultimates and optional Overload behavior now share one panel, position, size and lifecycle.
- AUTO follows the active weapon bar on new installations. Existing FRONT, BACK and BOTH choices remain intact.
- Enabled Overload behavior can prioritize an applicable morph on either bar outside BOTH mode. BOTH always retains both cards.
- **ULT Tracker → OVERLOAD SETTINGS** contains the behavior toggle, reserve warnings, ready reminder, optional native cancellation and PvP preference.
- Supported previous Overload options migrate into ULT Tracker. Existing SavedVariables are retained; an applicable legacy Overload layout can provide the shared panel's starting position and scale.
- Group Ultimate tracking retains its separate panel and ability filters.

## Three saved interface styles

Choose **Dashboard → Interface Style**:

- **Obsidian Studio**, the default: soft dark cards and clear section separation.
- **Ember Classic**: warm panels with orange borders and accent lines.
- **Tactical Compact**: flat framing, fine dividers and reduced background fill.

The style applies immediately across existing settings and HUD surfaces, follows Cross-sync and survives reloads. Fonts, icon identities, geometry, branding, readiness colors, item quality and Champion discipline colors remain stable. Theme selection adds no recurring animation or build scan.

## Move, resize and adjust in one place

- **MOVE HUD** and `/asmove` arrange enabled personal Ultimate, Group Ultimate and Support Coverage panels against the normal game interface.
- Corners scale the entire panel proportionally. Edges reshape the contents while icons remain square.
- The selected-panel toolbar controls scale, background opacity, reset and fit. Background opacity leaves text and icons visible.
- BOTH Ultimate cards stack in a narrow panel. Group rows and Support HUD contents adapt to available space.
- **DONE** or Escape saves and locks the layout. Combat, loading and menu transitions end placement safely without enabling disabled modules.

## Independent settings and community pages

The settings shell now belongs to Core and stays available when all tracking is disabled. Dashboard controls ULT Tracker and Support Coverage; Overload is an optional ULT behavior. Libraries sharing remains independent.

Website & About and Discord use native ESO controls. **OPEN DISCORD COMMUNITY** opens the configured Discord widget in an external browser after ESO confirmation. The addon does not embed HTML, poll member counts, invent an invitation or send group/build data through the link.

## Compatibility and verification

Existing account/server and character settings remain supported. Detailed remote builds still require a compatible sender; native group membership alone does not expose inventory, complete skills, Champion selections or masteries. Active full-build transport IDs **507/510** remain provisional pending formal reservation and coexistence validation.

The repository validator checks Lua 5.1/5.4 behavior, syntax, metadata and both installable packages. The full suite and generated companion share the same version metadata. The [ESO acceptance checklist](../docs/SUPPORT_COVERAGE_TESTING.md) includes migration, all display modes, theme persistence, corner/edge resizing, tooltip/dialog layering, travel/loading, real frame time and multi-client coexistence. Automated checks do not establish completed in-game acceptance.
