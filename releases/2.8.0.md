## Compatibility

Existing SavedVariables namespaces and default account/server layouts are preserved. Turning Cross-sync off creates a character profile from the current layout; turning it on keeps the current placement for the account. Build-sharing formats remain compatible with the included companion.

Native grouping does not provide full remote inspection. Compatible senders choose what to share. Missing information remains Unknown. Full build exchange remains opt-in; formal transport registration is required before public full-build-sharing distribution.
