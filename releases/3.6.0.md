# Alpha Squad UI 3.6.0 — Development candidate

## Personal HUD and placement

Personal Ultimate no longer changes ESO's native Ultimate button. The old suppression bridge, style hooks and input changes are removed so ESO and other action-bar addons retain ownership. Reload after updating to discard the previous runtime hooks.

The transparent design 2 keeps native icons, actual points/cost, thin progress, both normal bars and manual Overload control. Its green active marker now uses one larger native arrow texture instead of pixel scanlines. Hidden refreshes no longer rewrite stopped progress geometry.

MOVE HUD captures movement across the selected panel body, including group names and icons. Body dragging uses native movement without a frame poll; resize handles retain their distinct behavior. Transparent panels hide background controls. Saved placement and orientation remain supported.

## Languages and verified names

Dashboard offers English and French only. A supported game locale seeds the saved choice once; other locales default to English, and legacy automatic choices migrate. Later client-language changes do not override that choice.

Contextual weapon-bar and navigation labels, charging text and supported catalog terminology are corrected. Verified ID-based English/French names cover the supported catalog subset. Unmapped names preserve native fallback text; full native tooltips remain in ESO's client language. Item links, player names and protocol identities are unchanged. This is not a claim that every ESO name or tooltip has been translated by the addon.

## Group Ultimate coordination

The configuration offers nineteen curated support Ultimate families with seven defaults and verified morph matching. The actual reported skill icon and cost remain authoritative. Cryptcanon requires its dedicated Ultimate `195031`, not an inference from equipped gear. Unsupported and self-only sibling morphs do not acquire another morph's group effect. Corrected Dragonknight Standard coverage no longer attributes the group bonus to Shifting Standard or a debuff effect ID.

The crowned group leader selects a raid leader from current group accounts. Only the chosen raid leader edits shared filters; the crown can reassign the role. Compatible clients synchronize bounded settings metadata through separate LibGroupBroadcast protocol **511 / AlphaSquadRaidSettings**. Native OFF is respected and build/Ultimate sharing is never enabled by these settings. Missing or failed synchronization is exposed. Remote coordination is transient; personal layout and solo preferences remain local.

A compact food indicator before each account uses green **+**, red **−** and grey **?** for verified active, verified absent and unknown. It reuses fresh, identity-matched Support Coverage evidence without a new scan, sender or timer. Expired or missing evidence is unknown. Repeated reads and detail delivery preserve the original observation time.

## Validation and remaining acceptance

Automated regressions target native noninterference, placement hit areas, translations, morph matching, food expiry and authorization/context boundaries. The full validation gate checks Lua 5.1/5.4, metadata and both installable packages. Exact results belong to the successful run for the delivered commit; synthetic checks do not establish native rendering, latency or frame time.

Run the [3.6.0 client route](../docs/SUPPORT_COVERAGE_TESTING.md#360-interface-and-raid-coordination-acceptance) and record outcomes in [client acceptance](../docs/CLIENT_ACCEPTANCE.md). The historical 3.4.0 dropdown failure remains recorded. Native multiplayer/coexistence acceptance and formal reservation of provisional protocols **507/510/511** remain outstanding.

This cycle authorizes development on `dev` only: no PR, merge, tag, GitHub Release, ESOUI or website publication. See the [audit](../docs/AUDIT_3.6.0.md) for evidence and limits.
