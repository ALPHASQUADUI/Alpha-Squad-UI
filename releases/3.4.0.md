# Alpha Squad UI 3.4.0 — Development candidate

## Interface

- Compact transparent personal Ultimate HUD with both weapon slots, green active-bar marker, dimmed inactive icon and short progress animation. Retired AUTO/FRONT/BACK/BOTH selection; no skill names or repeated brand in gameplay HUDs.
- Optional Overload retains its mechanics: gold active state, green ready pulse and red stop warning.
- English/French addon language, following ESO by default, with a persistent Dashboard override and live presentation refresh. Native game names/tooltips retain the game language.
- Neutral gameplay framing, compact group rows and clearer Coverage/Builds layouts. Main settings keep their orange accent.
- Module-local Move HUD actions, orientation controls beside HUDs, return to native addon settings after Done/Escape, and a main Close action returning to gameplay.

## Correctness and performance

- Remove language-dependent support scoring and improve localized potion classification without treating equipment as consumption or buff uptime.
- Preserve sharing consent, profiles, native evidence and bounded transport. UI changes do not require remote build requests.
- Add targeted regressions for changed localization, native slot, lifecycle and navigation boundaries. Presentation-only work stops when hidden.

## Acceptance and publication

This is a `dev` candidate, not a published release or a native-client certification. Real ESO font/layout, state transitions, controller navigation, frame-time and multiplayer checks remain required. The current cycle authorizes no PR or release. Any later PR needs maintainer testing and explicit approval; only a human can approve and merge it into `main`.

Existing protocol registration/coexistence work remains independent of this interface update. No publication gate or acceptance statement is marked complete without evidence.
