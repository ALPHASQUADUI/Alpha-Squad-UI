# Alpha Squad UI 3.4.1 — Development hotfix

## Dashboard initialization

The maintainer reported duplicate native `BG` and `Scroll` controls while loading the 3.4.0 Dashboard. Both theme and language selectors created an anonymous instance of ESO's dropdown template, whose child names inherit the root name. The second instance therefore collided with the first.

Each private dropdown now receives a distinct addon-prefixed root from a serial retained on `Theme`. Reconfiguring an existing combo reuses its original dropdown. Native entries, selection behavior, scaling and the opaque popup fill remain instance-local, without overriding ESO's shared menu or unrelated controls.

## Regression coverage

The dropdown fixture now models the native global name registry and inherited child names. It covers theme and language selectors together, a third selector whose owner has no name, independent menu entries and opaque fills, repeated configuration reuse, and unrelated `BG` / `Scroll` controls. The former single-selector mock did not detect this native collision.

## Native retest and publication

After installing this build, reload ESO and open Dashboard. Alternate between both selectors, change theme and EN/FR/Automatic, close and reopen settings, and verify no duplicate-control errors or stale choices. Repeat at the actual UI scale and confirm other native menus remain unchanged. Continue the [client checklist](../docs/SUPPORT_COVERAGE_TESTING.md#341-interface-acceptance) for the 3.4 interface.

Native acceptance of 3.4.1 is pending. This hotfix belongs on `dev`; the current cycle authorizes no PR, merge, tag, GitHub Release or ESOUI publication. The 3.3.1 stability report is historical and does not approve this build. Protocol reservation and multiplayer coexistence requirements remain outstanding.
