# Ąlpha Şquad UI 3.3.1

Maintainer-accepted maintenance candidate. This update improves privacy defaults, group-data handling and UI lifecycle behavior while preserving existing saved preferences. On 2026-09-16, the maintainer reported the delivered version stable and authorized promotion to `main` and release preparation. Public release remains pending the separate prerequisites below.

## Privacy and sharing

- New full-suite and companion installations start sharing OFF. Existing saved choices remain supported; enabling a category is an explicit choice.
- Group transitions, combat and loading stop transfers and revoke pending Alpha Squad build frames through supported protocol controls. Unrelated library traffic is left alone.
- Failed queue revocation requires an explicit new ON after recovery, and this requirement survives a reload. Failed native deactivation is reported with a reload instruction; the addon cannot recall data already broadcast.
- Interrupted transfers have bounded lifetimes and cleanup that does not depend on an inspector staying open. Transfer failures and progress remain visible alongside partial set information.
- Inconsistent skill-line definitions cannot establish verified coverage when the native definition contradicts the received record. Unresolvable definitions remain distinct from verified facts.

## Interface and resource use

- Settings use consistent combat/loading opening rules and do not resume a suspended input owner over an unrelated scene.
- The Support HUD includes preparation issues even when all selected effect sources are present. Limited recipients remain distinguishable from full-group availability.
- Hidden Ultimate HUDs defer painting until they become visible. Settings refresh the active page instead of every hidden page.
- Unchanged readiness-only events avoid rebuilding coverage; full build scans remain available for changes that can alter native descriptions or dependent values.

## Distribution and validation

- Installable packages use an explicit reviewed file inventory and are scanned after assembly. Ignored runtime logs, backups and local data cannot silently enter a package.
- Metadata and secret checks cover proposed changes with redacted diagnostics. Historical remediation remains a separate, specifically authorized operation.
- Pinned GitHub Actions are updated to checkout 7.0.1, upload-artifact 7.0.1 and download-artifact 8.0.1. The exact standard Dependabot sign-off is handled only in an approved bot commit message; general file and private-data checks remain enforced.
- Development pushes run validation only. Public release requires a separate manual operation from reviewed main and recorded release gates; policy files do not claim that GitHub administration settings have been applied.
- Interrupted publication resumes matching drafts even before their tag exists. Ambiguous duplicate releases stop for review; validated source and asset hashes remain mandatory.

Update the full suite and companion together. No SavedVariables reset is required. Preserve a private backup before client testing; downgrades should restore the corresponding backup when needed.
