# Ąlpha Şquad UI 3.2.0

## Interface and navigation

- MOVE HUD waits for the native menu to finish closing before opening the editor. Normal gameplay/cursor-mode transitions no longer dismiss it. Repeated clicks cannot queue multiple editors.
- Done and Back save the arrangement and return to the addon window you came from. Closing Group configuration, Coverage or Builds also returns to the preceding addon window. Combat, loading and unrelated game menus stop placement without reopening settings.
- Workspace navigation is wider, keeping its labels readable. The style dropdown owns an opaque native backdrop so its options do not blend into the page below.
- About contains a direct **JOIN DISCORD** invitation. The separate Discord page and external widget link are removed; ESO still confirms external links before opening them.

## Ultimate tracking

- Overload keeps **Warning starts**, reserve alerts and its ready reminder. Automatic cancellation, its cutoff controls and obsolete cancellation actions are removed. You activate and stop Overload with your Ultimate binding.
- Group Ultimates uses one **Group tracking** switch on the parent ULT settings page. Configuration focuses on ability selection. Group HUD visibility, self-tracking and group ready-sound controls are removed; your own Ultimate stays in the personal HUD.
- The personal HUD follows the native active special bar during a transformation, resolving its actual Ultimate, morph, icon and cost. Available native effect duration identifies timed ACTIVE states. Normal weapon-bar preferences return afterward.
- Group tracking accepts the Ultimate identities actually reported by LibGroupCombatStats, including transformation Ultimates. Its front/back reports do not establish a teammate's transformed bar or active form.
- The same Ultimate on both bars uses the lower verified cost once. Partial reports for a changed ability cannot retain the previous ability's cost, and percentages remain below 100 until ready.

## Data and resources

- Support Coverage coalesces a burst of screen-resize events into one deferred refresh using current dimensions. The regression checks 200 notifications producing one pass.
- Builds no longer applies a separate short timeout to unchanged LibGroupCombatStats reports. Membership, identity, connection and native report validity still govern availability; repeated reads do not refresh evidence age.
- Security review found no new concrete injection or exfiltration defect in the examined transport paths. Peer-report validation, size/rate limits, expiry and independent sharing choices remain in place. This is a scoped review, not a security certification.

## Updating

Replace the `AlphaSquadUI` folder and reload. No SavedVariables reset is needed. Existing filters, geometry, display modes, sharing choices and supported warning preferences remain. A previously hidden group HUD becomes **Group tracking OFF** during migration instead of silently becoming visible. Retired cancellation and group controls no longer affect behavior.

The companion remains optional: Alpha Squad UI already includes the compatible sender. This update does not change the build wire format. The companion package uses the suite's current version metadata.

Use MOVE HUD once to review placement and preview states, then Done to return. Verify mouse and controller navigation, special bars, native menus and resolution changes against the [ESO acceptance checklist](../docs/SUPPORT_COVERAGE_TESTING.md).

The [video review](../docs/VIDEO_REVIEW_3.2.0.md) distinguishes recorded failures from code findings. Automated checks cover Lua 5.1/5.4, lifecycle and data logic, metadata and packaging. Native rendering, frame time and group coexistence still require client validation. Build transport IDs **507/510** remain provisional pending registration and coexistence validation.
