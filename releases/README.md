# Build downloads

Installable ZIPs are generated by GitHub Actions; this directory is documentation, not a release archive. Do not commit generated ZIPs or stale module-only builds here.

## Support Coverage test candidate

The current branch candidate is `2.7.0-support-coverage-test.4`, not a stable public release.

1. Open [Support Coverage branch tests](https://github.com/ALPHASQUADUI/Alpha-Squad-UI/actions/workflows/support-coverage.yml).
2. Select the successful run whose branch is `support-coverage` and whose commit matches the version you intend to test.
3. Download `AlphaSquadUI-support-coverage-test` from **Artifacts** while signed in to GitHub.
4. Extract the downloaded artifact and then its enclosed versioned addon ZIP. Install the `AlphaSquadUI` folder as described in the [root README](../README.md#installation).

`SupportCoverage-review-source` is a separate source-review artifact containing code, tests and documentation. It is not the installable addon package, and its presence does not prove validation passed: it can also be uploaded by a failed run.

Branch pushes generate these artifacts without creating a pull request, release or tag. In-game acceptance is tracked in the [test checklist](../docs/SUPPORT_COVERAGE_TESTING.md). Experimental sharing remains off by default; provisional protocol IDs 507–510 must be reserved and coexistence-tested before public sharing is released.

## Stable / PR validation builds

The [Validate AlphaSquadUI workflow](https://github.com/ALPHASQUADUI/Alpha-Squad-UI/actions/workflows/validate-addon.yml) produces an `AlphaSquadUI` artifact containing `AlphaSquadUI.zip` for its validated commits. Check the run's branch and commit before downloading: a PR build is not a stable release.
