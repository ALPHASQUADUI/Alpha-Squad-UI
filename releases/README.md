# Build downloads

Installable ZIPs are generated by GitHub Actions; this directory is documentation, not a release archive. Do not commit generated ZIPs or stale module-only builds here.

## Support Coverage test candidate

The current branch candidate is `2.7.0-support-coverage-test.5`, not a stable public release.

1. Open [Support Coverage branch tests](https://github.com/ALPHASQUADUI/Alpha-Squad-UI/actions/workflows/support-coverage.yml).
2. Select the successful run whose branch is `support-coverage` and whose commit matches the version you intend to test.
3. Download `AlphaSquadUI-support-coverage-test` from **Artifacts** while signed in to GitHub.
4. Extract the downloaded artifact and then its enclosed versioned addon ZIP. Install the `AlphaSquadUI` folder as described in the [root README](../README.md#installation-and-branch-test-download).

`SupportCoverage-review-source` is a separate source-review artifact containing code, tests and documentation. It is not the installable addon package, and its presence does not prove validation passed: it can also be uploaded by a failed run.

Branch pushes generate these artifacts without creating a pull request, release or tag. In-game acceptance is tracked in the [test checklist](../docs/SUPPORT_COVERAGE_TESTING.md). Experimental sharing remains off by default; active provisional protocol IDs 507/510 must be reserved and coexistence-tested before public sharing is released.

## Sharing-only companion

**AlphaSquadBuildShare** is the optional companion for group members who want to send build data without installing the full UI. Install the companion folder, LibGroupBroadcast, LibAddonMenu-2.0 and LibDebugLogger as separate addons, then explicitly opt into experimental sharing using `/asbuildshare on`. Use `/asbuildshare off` to stop and `/asbuildshare status` to inspect its state. The default is OFF. It must use a compatible candidate version. Do not install a source-review archive as the companion.

The repository generates it with `python tooling/build_companion.py OUTPUT.zip` from `companion/` and shared source files. Download the separate **AlphaSquadBuildShare** artifact from the same successful branch run and extract its **AlphaSquadBuildShare.zip**; it contains its own manifest and sharing runtime. The full suite's receiver and the companion are different installations of the compatible protocol, not two senders to enable simultaneously on one client.

## Stable / PR validation builds

The [Validate AlphaSquadUI workflow](https://github.com/ALPHASQUADUI/Alpha-Squad-UI/actions/workflows/validate-addon.yml) produces an `AlphaSquadUI` artifact containing `AlphaSquadUI.zip` for its validated commits. Check the run's branch and commit before downloading: a PR build is not a stable release.
