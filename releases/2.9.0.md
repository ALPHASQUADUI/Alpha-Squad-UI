# Ąlpha Şquad UI 2.9.0

## Clearer controls and placement

- Restored the Ą and Ş in the static orange brand gradient; UI stays white and @SeRuM1 retains the blue gradient.
- Added one **MOVE HUD** action in the sidebar and `/asmove`. Place enabled panels against the normal game interface, then Done or Escape saves and locks them.
- Removed redundant per-module Lock/Unlock & Move controls. Placement preserves Dashboard choices and normal visibility preferences.
- The personal Ultimate panel yields when an applicable Overload panel already handles the slotted morph. Group Ultimate tracking stays independent.
- Native link-confirmation dialogs appear in front of addon windows.

## Automatic, visible sharing setup

- New installations configure the supported build, Ultimate and set sharing categories ON once when dependencies are available.
- Existing saved OFF choices remain OFF. The companion also defaults ON only for a new installation.
- Libraries reads and changes the actual matching native library settings without navigating to another addon page.
- Missing or incompatible integrations show their unavailable state. Other protocol settings and set-incognito choices are preserved.
- Tracking, layout and Cross-sync remain independent of sharing preferences.

## Compact preparation

- Every Coverage effect fits on one page under Buffs, Debuffs, Group Sets and Group Mythics, with additional compact columns for dense categories.
- Native icons, status colors, ON/OFF switches and contributor counts replace tall repeated provider rows. Hover a count for every provider and their exact reported sources; click to open the named build.
- Build set headlines use the highest known FRONT/BACK total. Two-handed weapons count as two pieces without combining both weapon bars.
- Genuine excess pieces remain visible, with a warning derived from the native set's final bonus threshold. Incomplete data never produces a guessed total or warning.
- Enlarged the native body silhouette and adjusted armor placement while retaining the jewelry and weapon sections.
- Strengthened remote-equipment consistency and Champion-source checks; malformed or incomplete reports cannot certify a complete build.

## Compatibility and validation

Existing account/server and character settings remain supported. Detailed remote builds still require a compatible sender; native group membership alone does not expose inventory, complete skills, CP or masteries. Full build transport identifiers remain provisional pending formal registration and coexistence validation.

The repository validator checks Lua 5.1/5.4 behavior, syntax, metadata and both installable packages. New regressions cover native library state, saved OFF preferences, placement lifecycle, complete-grid bounds, bar counts, excess warnings and malformed shared evidence. The [ESO acceptance checklist](../docs/SUPPORT_COVERAGE_TESTING.md) covers native rendering, travel/reload behavior, real frame time and multi-client coexistence; these are not claimed as completed by automated checks.
